# KAJY STATS — Site de statistiques football

## Mise à jour quotidienne
1. Récupère le nouveau fichier `data/AAAA-MM-JJ.json`
2. Remplace le fichier dans le dossier `data/`
3. Envoie sur GitHub → c'est en ligne !

## Hébergement GitHub Pages
1. Crée un dépôt nommé `kajystats`
2. Glisse-dépose TOUS les fichiers dedans
3. Dans Paramètres → Pages → Source : choisis `main` branch → Save
4. Lien : `https://tonpseudo.github.io/kajystats/`

## Prochaine étape
- Remplace les images dans `images/` par tes propres logos
- Chaque jour, je te donne le nouveau `.json` à déposer
